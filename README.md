# Practice site

A copy of World Art Review for trying out Artiscope Digital Home. It is not
a real website: it has no domain, every page tells search engines to ignore
it, and the website agents never work here.

- People are given this site in the console's People screen, like any other site.
- The admin can start it again from World Art Review at any time, from the
  site's Overview in the console. That replaces its words, pages, theme and
  photos. World Art Review itself is never touched.
- It is published on every push to main, at an unlisted address.

Nothing here is checked for facts or sources, so never copy anything from
here to a real site.
